ETHsliv — статический сайт (без сервера и установки)
=====================================================

КАК ОТКРЫТЬ
  Распакуйте архив и дважды кликните по index.html — сайт откроется в браузере.
  Всё работает без интернета: шрифты лежат в папке fonts.

КАК ДОБАВИТЬ ТЕКСТ В РАЗДЕЛ
  1. Откройте index.html в любом текстовом редакторе (Блокнот, VS Code).
  2. Найдите внизу блоки вида:

       <script type="text/plain" class="entry" data-section="instagram">
       Заголовок записи
       Сам текст записи...
       </script>

  3. Первая строка внутри блока — заголовок, всё остальное — текст.
     Пустая строка = новый абзац. Ссылки https://... становятся кликабельными.
     Текст вставляйте как есть — ничего экранировать не нужно.
  4. Чтобы добавить ещё одну запись, скопируйте блок целиком и вставьте под ним.
  5. Блоки-примеры («Пример записи…») удалите или перезапишите.
  6. Сохраните файл и обновите страницу.

  Значения data-section для разделов:
     instagram, instagram-web, tiktok, youtube, facebook, other,
     discord, pinterest, bluesky, reddit, xiaohongshu, lendy

ТЕКСТ НА ГЛАВНОЙ («Зачем покупать приватку Эфира…»)
  В index.html найдите <template id="tpl-home"> — там логотип, подпись и текст,
  правятся прямо в файле.

КАК ПЕРЕИМЕНОВАТЬ / ДОБАВИТЬ / УБРАТЬ / ПЕРЕСТАВИТЬ РАЗДЕЛ
  Откройте js/app.js — вверху список SECTIONS. Одна строка = один раздел
  ({ id: 'tiktok', title: 'TikTok' }). Порядок строк = порядок на главной.
  id — латиницей, такой же нужно указывать в data-section у текстов.

ЦВЕТА И ОФОРМЛЕНИЕ
  css/style.css — вверху блоки :root с цветами (основной синий — --mast и --accent).
  Тема (светлая/тёмная) берётся с устройства; кнопка в шапке переключает
  её вручную, выбор запоминается в браузере.

ЧТЕНИЕ
  В каждом разделе есть кнопки размера текста (A / A), «Раскрыть все» и, если
  записей 5 и больше, поиск (клавиша «/» ставит курсор в поиск).

КАК ОПУБЛИКОВАТЬ В ИНТЕРНЕТЕ
  Это обычные статические файлы, подойдёт любой хостинг:
  — Netlify Drop (app.netlify.com/drop): перетащите папку ETHsliv в окно браузера;
  — Cloudflare Pages или GitHub Pages: загрузите содержимое папки.
  Главное — чтобы index.html лежал в корне.

СОСТАВ
  index.html      страница и ВСЕ тексты
  css/style.css   оформление
  css/fonts.css   подключение шрифтов
  fonts/          шрифты Onest и Unbounded (лицензия SIL OFL)
  js/app.js       разделы, раскрытие записей, поиск, копирование, тема
